# Weekly review

1. Identify the requested workspace evidence. If a file is missing, say so.
2. Read the evidence and count failed login lines when relevant. Distinguish line counts from unique attacks.
3. Summarize findings, the exact supporting observations, uncertainty, and next actions.
4. If a report file is requested, propose the path and complete content with workspace_write. Wait for approval.
5. Verify the tool result before reporting a successful write. Do not propose remediation without explaining its effects.
